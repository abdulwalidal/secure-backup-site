# Secure Backup - Official Website

The official landing page, download hub, and cryptographic documentation for [Secure Backup](https://github.com/abdulwalidal/secure-backup).

## Features
- **Client-Side OS Sniffing:** Automatically detects macOS, Windows, and Linux.
- **Dynamic GitHub Releases:** Queries releases API for instantaneous live binary downloads.
- **Cryptographic Transparency:** Full architectural documentation for Argon2id and AES-256-GCM AEAD.
- **High Performance:** Pure static HTML5, CSS3, and modern Vanilla JS (zero build step, instant edge delivery).
- **Vercel Ready:** Pre-configured with security headers and clean URL routing.

## Deployment
Deployed on [Vercel](https://vercel.com).

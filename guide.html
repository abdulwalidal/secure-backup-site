Quickstart & User Guide

How to install Secure Backup, create encrypted archives, connect cloud storage, and restore data.

1. Installation

Download the binary for your platform from the Download Hub:

  • Linux (AppImage): Make executable with chmod +x secure-backup_*.AppImage and run directly. Or install the .deb package with sudo dpkg -i secure-backup_*.deb.
  • Windows: Run secure-backup_*.msi installer or launch the standalone portable .exe.
  • macOS: Open the .dmg disk image and drag Secure Backup into your /Applications directory.

2. Creating Your First Backup

Follow these simple steps in the dashboard:

  • Click Select Folder and choose the source directory you wish to archive.
  • Enter a memorable, robust Passphrase. Secure Backup uses Argon2id to derive a cryptographic 256-bit key from this passphrase.
  • (Optional) Toggle default exclusion filters to automatically skip temporary directories (such as .git, node_modules, and build caches).
  • Click Start Backup. Files are scanned, hashed with SHA-256, and encrypted with authenticated AES-256-GCM.

3. Connecting Google Drive Vault

To safely mirror encrypted archives to cloud storage:

  • Navigate to the Settings tab and locate the Google Drive provider card.
  • Click Connect. A secure browser window opens via OAuth 2.0 with PKCE verification.
  • Grant permission for Secure Backup to manage its isolated vault folder (drive.file scope).
  • Once connected, return to the Backup History tab and click Sync to Cloud on any snapshot.

4. Verifying & Testing Passphrases

Never wait for a disaster to discover a forgotten passphrase:

  • In the Backup History list, click Test Unlock on any snapshot.
  • Enter your passphrase in the verification modal.
  • Secure Backup validates the passphrase against the manifest AEAD polynomial tag and pre-computed digest in memory without writing files to disk.

5. Restoring Files & Disaster Recovery

When you need to restore your data:

  • Click Restore on the desired snapshot in your history.
  • Choose the destination folder and input your passphrase.
  • Every restored file is verified against its authentic AEAD tag and SHA-256 integrity hash.
  • Disaster Recovery Mode: If your local computer crashed or hard drive was wiped, install Secure Backup on a new PC, connect your Google Drive account, and click Discover Cloud Snapshots in the Cloud tab to rebuild your entire catalog.

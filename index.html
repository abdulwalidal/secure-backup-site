How It Works

Four simple steps to impenetrable, verifiable backups.

01

Select Source Directory

Pick any local folder or project. Secure Backup scans files and computes SHA-256 integrity hashes.

02

Derive Keys with Argon2id

Your passphrase is hashed into a 256-bit key using Argon2id with 19 MiB memory cost and fresh OS salts.

03

AES-256-GCM Encryption

Files and manifests are encrypted with authenticated ciphertexts and 12-byte cryptographically random nonces.

04

Sync & Disaster Restore

Upload encrypted snapshots to Google Drive. Restore anytime locally or reconstruct catalog on a fresh PC.

Cryptographic Specification & Threat Model

Transparent, auditable security primitives implemented in pure Rust.

Security Component Primitive / Standard Technical Specification
Key Derivation Argon2id (v0x13) 19 MiB memory cost, 2 iterations, 1 lane, 16-byte random salt from OS CSPRNG.
Symmetric Cipher AES-256-GCM Authenticated encryption with associated data (AEAD), unique 12-byte nonce per file.
Integrity Verification SHA-256 & GCM Tag Every file verified via SHA-256 hash plus AES-GCM 16-byte polynomial authenticator tag.
Cloud Auth Protocol OAuth 2.0 PKCE SHA-256 Code Challenge with loopback redirect on localhost. Restricted drive.file scope.
Network Resiliency Exponential Backoff Automated retry on 429 / 5xx responses with randomized exponential jitter.
Zero-Knowledge Promise: Your passphrase is never saved to disk, transmitted over the wire, or written to SQLite. Neither Google, cloud providers, nor the application developers have access to your keys or decryption data.

Frequently Asked Questions

Common questions about cryptography, cloud storage, and backup restoration.

Can Google or cloud providers see my unencrypted files?

No. All files and snapshot manifests are encrypted on your local computer before any data leaves your machine. Google Drive only stores opaque AES-256-GCM ciphertext chunks. Google cannot inspect the filenames, directory structure, or file contents.

What happens if I forget my backup passphrase?

Because Secure Backup adheres strictly to zero-knowledge cryptography, there is no back door, reset link, or recovery key stored anywhere. If you lose your passphrase, the ciphertext cannot be decrypted. We recommend saving your passphrase in a reliable password manager.

Does Secure Backup require an internet connection?

No. Creating encrypted local backups, testing passphrases, and restoring from local storage works 100% offline. An internet connection is only needed when you choose to synchronize snapshots to your Google Drive account.

What if my computer crashes or hard drive dies?

Install Secure Backup on any new machine, link your Google Drive vault, and click "Discover Cloud Snapshots". The application downloads the encrypted manifests and reconstructs your snapshot ledger, allowing you to restore all files.
